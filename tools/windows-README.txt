Just3D @VER@
======
Double-click Just3D-@VER@.exe. It opens Just3D in its own window (uses Microsoft Edge, which comes with Windows 11; Google Chrome also works).

First launch: Windows may show "Windows protected your PC" because the file is not code-signed.
To clear it once: right-click Just3D-@VER@.exe > Properties > tick "Unblock" > OK.
(Or click "More info" > "Run anyway".) Unblock the .zip before extracting to avoid it on every file.

To open a model quickly: drag an .obj file onto the Just3D window, or onto Just3D-@VER@.exe.

Nothing is installed. Settings are stored in %LOCALAPPDATA%\Just3D. Delete that folder and Just3D-@VER@.exe to remove everything.
Press Shift+? inside the program for the keyboard shortcut list.
