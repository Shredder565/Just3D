The sheet's views are cut out and POSTed as front, side, back, top (PNG) plus image (the best single view). The reply must be a mesh file. See the README for the exact contract and the example server.

Import a mesh and make it pure quads

.glb .obj .stl .ply, triangles or quads
Any mesh works: a scan, an AI result, something you modelled. It is rebuilt as all quads and every point is snapped back onto the original surface, so shape and detail are kept as far as the quad count allows.
